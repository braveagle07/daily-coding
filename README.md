# Daily Coding Practice

A personal repository for daily programming practice, problem-solving exercises, and learning notes in Python and Java.

This repo is used to improve logic, data structures, algorithms, and consistency through small daily coding challenges.

## Overview

The repository currently contains:
- Python daily practice scripts
- Java fundamentals and small exercises
- Dynamic programming examples
- LeetCode-style problem solutions
- Beginner-friendly problem-solving notes
